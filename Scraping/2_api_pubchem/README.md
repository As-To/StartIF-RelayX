# 🧪 PubChem API Client

Ce dossier est réservé pour les outils PubChem (alternative à ECHA).

PubChem est une base de données chimiques du NIH (National Institutes of Health) qui offre une API gratuite et accessible.

## Pourquoi PubChem ?

- ✅ API publique et gratuite
- ✅ Pas de blocage anti-bot
- ✅ Données similaires à ECHA
- ✅ Plus facile à automatiser

## Installation

```bash
pip install requests
```
